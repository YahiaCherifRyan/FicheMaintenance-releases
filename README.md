# Fiches Maintenance : versions

Ce dépôt publie les versions de **Fiches Maintenance**, application Windows de fiches d'intervention de maintenance GTB/GTC.

- **Télécharger** : onglet [Releases](../../releases), puis le fichier `Setup` (installeur) ou la version portable.
- **`latest.json`** : décrit la dernière version disponible. L'application le lit pour prévenir qu'une mise à jour existe. Aucune donnée n'est envoyée.

Le code source n'est pas publié ici.
